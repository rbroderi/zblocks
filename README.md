# ZBlocks

Server-side puzzle blocks for Purpur 26.3, powered by Nexo. The current implementation is in [purpur/](purpur/); see [installation and build instructions](purpur/NEXO.md).

Includes movable push blocks, redstone pressure bases, weapon/projectile activation, transient ghost blocks, reset hourglasses, six-direction ridged edges and bombs with fuse/explosion effects. Clients use the server resource pack and need no ZBlocks mod.

The original Minecraft 1.12.2 mod remains in [zblocks/minecraft1.12.2/](zblocks/minecraft1.12.2/) for reference. It is separate from the Purpur plugin.
